# Структура домена

```text
RWorkspace [workspaces]
│  Конфигурация рабочего пространства, startup Composition,
│  режим данных и подключённые интеграции.
│
├── RFacet [facets]
│   Определение динамической оси контекста: identity, название,
│   оформление и позиция в configuration cascade.
│   │
│   └── RFacetDocument [facet_documents]
│       Выбираемое значение фасета с configuration contribution.
│       Identity уникален только внутри родительского фасета.
│
├── RFolder [folders]
│   Дерево организации обычных Domain documents. Папки коллекций
│   типизированы; Workspace-папки могут содержать разные коллекции.
│
├── RType [types]
│   Source-first тип доменных данных.
│
├── RQuery [queries]
│   Source-first определение запроса данных.
│
├── RDataView [data_views]
│   Проекция или преобразование данных запроса либо Store.
│
├── RComposition [compositions]
│   Source-first оркестрация runtime-документов. Одна Composition
│   может быть назначена startup-корнем Workspace.
│
├── RStore [stores]
│   Source-first определение хранилища состояния.
│
├── RStream [streams]
│   Source-first поток сообщений.
│
├── RSimulation [simulations]
│   Source-first сценарий изолированного запуска Composition.
│
├── RUpdate [updates]
│   Source-first изменение, связанное с Store того же Workspace.
│
├── RMock [mocks]
│   Встроенные тестовые данные или ссылка на внешний provider.
│
├── RComponent [components]
│   Самостоятельный source-first UI-компонент.
│
├── RAction [actions]
│   Source-first действие и его runtime contract.
│
├── RFilter [filters]
│   Определение фильтра и его полей.
│
├── RConverter [converters]
│   Зарегистрированный преобразователь значений.
│
├── RComputation [computations]
│   Переиспользуемое вычисление с входами и выходами.
│
├── RVocab [vocabs]
│   Справочник; может ссылаться на Auth Profile того же Workspace.
│
├── RI18nBundle [i18n_bundles]
│   Набор переводов по локалям.
│
├── RAuthProfile [auth_profiles]
│   Конфигурация authentication adapter и credential references.
│
├── RNavigation [navigations]
│   Дерево навигации.
│
├── RStyle [styles]
│   Source-first таблица стилей.
│
└── RConfiguration [configurations]
    Source-first схема дополнительных configuration values.
```

Все перечисленные сущности принадлежат Workspace. История, commits, releases и
backups фиксируют состояние Workspace, но не являются дочерними Domain documents.
